# Delivery Insights Assistant

A local AI chatbot that answers questions about food-delivery operations in plain English. It turns each question into SQL, runs it safely against a SQLite database, and explains the result.

## How it works
- A local LLM (Qwen2.5 via Ollama) uses tool calling to write SQL queries.
- `db.py` enforces safety: read-only connection, a single SELECT only, row limit.
- The chat keeps conversation history, so follow-up questions work.
- The database is synthetic data generated by `seed.py`.

## Run it (from the project root)
    brew install ollama && brew services start ollama
    ollama pull qwen2.5:1.5b
    uv sync
    uv run python -m delivery_insights_agent.seed
    uv run python -m delivery_insights_agent.agent

## Example questions
- Which restaurant has the slowest average delivery time?
- What is the cancellation rate by city?
- Which driver earned the most in tips?

## Tests
    uv run pytest
